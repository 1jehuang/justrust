## Stacks

- **stock**: plain cargo + system rustc, no justrust
- **jr-nocache**: justrust, every cache off: toolchain, forks, integration only Env: `{'JUSTRUST_DEPCACHE': '0', 'JUSTRUST_BUILD_SCRIPT_CACHE': '0', 'JUSTRUST_PEER_CACHE': '0', 'JUSTRUST_REMOTE_CACHE': '0'}`.
- **justrust**: justrust defaults, private depcache warmed by the warmup round

## Workloads

- **reference-loop**: edit a #[test] fn in the 118k-line UI crate, run its tests. `test -p jcode-desktop-ui --lib -- fps_counter` (suite scenario `desktop-test-edit`)
- **body-check**: one-line body edit, `check` (the inner type-check loop). `check -p jcode-desktop-ui` (suite scenario `desktop-body-check`)
- **first-error**: time to the first type error after an edit. `check -p jcode-desktop-ui` (suite scenario `desktop-type-error`)
- **deep-edit**: body edit deep in the graph (16 crates rebuild), run tests. `test -p jcode-desktop-ui --lib -- fps_counter` (suite scenario `desktop-jcode-core-body`)
- **noop-test**: no edit: fixed cost of a `test` call. `test -p jcode-desktop-ui --lib -- fps_counter` (suite scenario `desktop-noop-test`)
- **small-crate**: body edit in a small crate (justrust), `test` (all binaries). `test -- summary::` (suite scenario `justrust-body-test`)
- **cold-check**: fresh target dir (new checkout, worktree): `check`. `check -p jcode-desktop-ui` (suite scenario `desktop-cold-check`)
