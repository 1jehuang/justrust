## Frozen semantic contract

A return-position `impl Trait` occurrence has a canonical defining declaration, ordered enclosing and callable type arguments, return-site ordinal, declared bounds and equality constraints, and canonical named capture identities. Source checking may use only its declaration-owned public bounds. It must not inspect a defining callee body to select methods or establish type equality. Argument-position `impl Trait` remains an anonymous generic with an unspellable declaration identity.

The defining body chooses one hidden type for each opaque occurrence. All returning paths must agree, including explicit returns and the tail. The hidden type must satisfy every declared bound and associated equality. An immutable record is published as TEMPLATE_BODY output 2. Stored closure template branches must also finalize this output. No result is kept in a mutable fact slot.

The defining body must publish a concrete hidden record even when unused. Direct or mutual recursion and diverging-only definitions without a concrete witness are explicitly unsupported during CHECK, not deferred until BUILD. Hidden types containing another opaque identity are also explicitly unsupported until a cycle-safe declaration protocol is implemented. Caller checking never reads a callee's hidden body to complete such a definition.

An OpaqueWrap seals one checked value. Its result type, defining owner, completion, public bound proof and hidden representation correspondence must be replayed. A caller cannot construct a defining wrapper or learn additional concrete methods. Unsupported recursive hidden-type or representation dependencies are explicit diagnostics, never placeholder types.

## Abstract carriers

Opaque values use a declaration-owned opaque carrier family extending the same canonical family protocol as parameters and projections. The identity includes the full ordered opaque application and declared capture family. A tail is not a projection into a hidden field. Universal ownership preserves origins and rejects returned local escapes. Closed representation realization maps every actual channel to an admitted capture origin through the exact hidden record. No-reference approximations and fabricated hidden field paths are forbidden.

## Graph and instance migration

Existing MONO_PLAN is known whole-program debt. It currently resolves every trait target synchronously before instance BODY, which cannot resolve a public opaque bound correctly. Opaque physical dispatch must move to per-instance consumers, not add a hidden-type map to MONO_PLAN.

Canonical instance keys encode a resolved declaration and ordered typed actuals injectively using tagged, length-delimited words. Nominal types encode their source declaration and actuals, not local application IDs or names. Snapshot identity is included for process-local authority. Decoding must validate the exact metadata and canonical target before executable use. Unsupported key forms fail explicitly.

A canonical body producer is independent of the global MONO_PLAN slot. Existing BODY(index) may become a thin alias to that producer, never a second computation. A per-instance consumer requests both the exact defining TEMPLATE_BODY output 0 and output 2 before awaiting either. Output 0 must retain its canonical source publication. An immutable OpaqueDefinitionProof compares every chosen OpaqueWrap's full identity, result and operand type with the output-2 record, and retains only a fresh immutable publication identity seal and that occurrence set. No source body, facts, world, schema or budget is retained in the proof. Replay borrows the exact graph-read publication. Bounds alone cannot authorize a replacement hidden type. Replaying an instance also requires the same snapshot/world and ordered actuals. Only then may normalization use the hidden record. A later executable consumer must replay a declared-bound call against that representation before demanding the concrete callee instance. Distinct opaque dispatch authorizations remain distinct facts even when their proven physical callee bodies can share one canonical instance.

Build may demand reachable object facts and join required outputs at its existing root. CHECK must not demand physical normalization or codegen. No new parameterless producer, shared cache, side slot, whole-hidden-type join or all-body source barrier is permitted.

## Retained-payload audit

The publication seal is an `Arc<OriginalIdentity>` containing only a private byte, minted once by the canonical publication factory. Proofs retain this seal, occurrence IDs and immutable semantic metadata, never a publication, CFG, facts, world, schema, planning context, budget or trait-object capsule. Replay borrows those authorities through graph-read context.

The recursive `Ty` payload audit on the integrated closure/carrier baseline covers every variant. Scalar, declaration, binder, parameter, site and region identities are values. Structural types recurse only into types. Associated projections and dynamic traits retain resolved declaration IDs and ordered type metadata. Nominal definitions retain IDs, names, module/visibility values, ordered type arguments and field/variant metadata. Their existing recursive `Weak` back edges point only to the same immutable definitions, not a world or interner. Closure metadata retains owner/provider IDs, ordered types and capture places consisting only of local IDs and integer projection coordinates. Opaque metadata retains defining owner/site, ordered types, declared bound/equality metadata and named region IDs. None of these fields reaches mutable compiler authority. Any future field addition must preserve this property or replace retained metadata with frozen identities and borrowed replay.

6. Relevant stock-differential suites, full_programs, shared-type lib controls and all-target compilation remain required. A codec-only or structural compilation result is not feature completion.
