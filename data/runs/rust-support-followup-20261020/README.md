# Rust support follow-up receipts

Compact projections of `justrust export` records for the run IDs cited by the remediation feature documents and `RUST-SUPPORT-FOLLOWUP.md`. Fields retain run identity, command category, exit status, diagnostics, test results and measured wall time. Hosted exports redact private paths and source details.

The baseline failures are intentional evidence of existing limitations, not passing acceptance gates. Interrupted runs and intermediate compilation failures are not substitutes for final successful validation. Full Rust support is not established by these records.
