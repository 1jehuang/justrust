# Owned Cargo development

Cargo is maintained inside justrust at `toolchain/cargo`, alongside the compiler.
The justrust root `AGENTS.md`, `CONTRIBUTING.md`, and
`docs/toolchain-vendoring.md` govern edits, tests, measurements, and releases.

The retained chapters describe [architecture](implementation/architecture.md),
[implementation](implementation/index.md), and [testing](tests/index.md).
They are technical references, not upstream contribution approval requirements.
