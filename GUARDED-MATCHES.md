# Bounded guarded matches macro

Status: implemented and validated in debug/release and the complete 3,140-test/160-binary regression suite. Full Rust remains open.

Extend the checked builtin `matches!(expression, pattern if condition)` only. Lower through the existing two-arm Match with the matched arm evaluating an ordinary If(condition, true, false). The guard is evaluated exactly once only when the pattern matches; existing pattern bindings are visible only within the matched arm and guard. The scrutinee remains evaluated once. A false guard produces false, not another pattern attempt. Require the existing Bool/Never condition semantics, source ownership, lexical macro selection, metered allocation and all-source checking. A retained source-arm marker makes the checker require genuine Copy for every pattern binding and reject mutable pattern bindings before publishing the pattern, even in dead source. Non-Copy and mutable binding guards are an explicit Unsupported boundary in this slice, preventing ordinary If lowering from permitting moves or writes that real Rust guards forbid. Wildcard/nonbinding patterns may still match a non-Copy scrutinee. Do not add a general match-arm guard IR or backend path, permit unsupported patterns, or bypass borrow checking. Ordinary match guards remain explicitly unsupported.

Acceptance: the 23 frozen stock sources remain byte-identical. The native partition is ten executable cases (including one abort), seven Unsupported, five Invalid and one earlier Syntax boundary. Debug/release each passed 92 CLI and 92 observed graph cells with 20 runtime executions per path, twelve public authority controls, and the unchanged 21-source historical corpus with its guard witness promoted. Three Copy-binding checker groups and five parser groups also pass. All-target checks, strict lint and formatting pass. Fourteen exact failed/successful receipts are retained in `data/runs/xps14/2026-10-18-guarded-matches.jsonl`. Earlier formatting/token boundaries are recorded rather than counted as guard coverage.
All three delimiters and the optional trailing comma retain their source separator rules. Invalid guard types, names, ownership and unreachable source remain checked. General match guards, non-Copy/mutable binding guards, formatting, unsupported patterns and full Rust support remain open. No performance claim is made.
