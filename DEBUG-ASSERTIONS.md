# Bounded debug assertions

Status: implemented and validated in debug/release and the complete 3,158-test/162-binary regression suite. Full Rust remains open.

`debug_assert!`, `debug_assert_eq!` and `debug_assert_ne!` use the supported scalar comparison and literal-message domains of the existing assertions. Native program configuration, not the compiler host profile, determines execution. The native default remains enabled. `--debug-assertions yes|no` and `SourceOptions.cfg.set_debug_assertions(bool)` explicitly select it. A private authoritative configuration bit is checked against cfg membership, captured immutably in `PreparedSource`, and propagated through root and macro-child parsers. Reserved user cfg and forged public cfg membership cannot override it.

Disabled assertions remain parsed, name-resolved and type-checked under a checked false conditional, but their arguments and panic path do not execute. Enabled assertions evaluate operands once and reuse existing checked assertion/panic paths. Lexical macro lookup, source occurrence authority, budget accounting and all-source validation are preserved. The legacy direct parse API retains its original line/column diagnostic format while carrying the configured parser value. No general formatting, trait equality, optimizer or full Cargo profile implementation is implied.

The 53 independently measured stock sources are byte-identical and ordered as retained in the receipt. Both stock configurations have 43 compiled and ten rejected sources; enabled stock has fifteen aborting cases and disabled stock has none. The bounded native partition is 22 live, twelve aborting when enabled, seven invalid and twelve Unsupported. Each compiler build profile exercises 424 CLI and 424 observed graph CHECK/BUILD cells across native settings and workers1/8, with 136 executable checks per path. Earlier literal/format/operator boundaries remain explicit rather than being counted as native support.

Seven public authority controls and seven private configuration/parser/CLI tests cover immutable settings, cfg consistency, cold invalid operands, foreign metadata, lexical shadowing and allocation failure. Debug and release native matrices, all-target checking, strict lint and formatting passed. The unchanged historical assertion witness is promoted to enabled native abort. Twenty exact gate receipts and the complete 3,158-test result are recorded in FINDINGS.md and `data/runs/xps14/2026-10-18-debug-assertions.jsonl`. No full Rust or performance claim follows from this milestone.
