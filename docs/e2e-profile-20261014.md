## Dominant observation: synchronization serialization

Source sync totals 314.335 seconds, nested within the remote category, about 45.65% of all hosted end-to-end wait. Do not add it again. Three sync waits alone were 120.048, 101.036 and 66.686 seconds.

Run `20261014-074749669-140934645` took 135.020 seconds end to end, but recorded host work was only 11.123 seconds. Its 120.048-second sync closely matches daemon logs reporting 119.68 seconds waiting for a lock, 0.11 seconds pushing and 0.26 seconds in the barrier. Another source mirror transferred 66,244 files in 117.24 seconds. The duration/time correspondence strongly implicates daemon-wide sync serialization behind unrelated toolchain source mirroring. Daemon logs lack per-run IDs, so this is corroborating evidence, not exact request-level tracing.

A smaller typical UI-test example, `20261014-074644711-140934559`, took 12.235 seconds: 6.792 compilation, 4.507 tests, 0.603 outside recorded host, with the remainder startup/gaps/tail. The full workspace-test sample `20261014-080145774-339510434` spent 43.461 seconds in tests versus 4.583 seconds compiling and exited 101. Test failures are retained, not counted as successful acceptance.

No compiler pass timings were captured. Frontend, codegen, incremental and linker wall attribution is unavailable in this run. Linker CPU must not be substituted for linker critical-path wall time.

## Coverage failures and next measurement

Pre-build `20261014-074659664-140934428` failed at pinned Desktop `tests/version.rs:7:49`: `environment variable CARGO_BIN_EXE_jcode-desktop not defined at compile time`. Another pre-build, `20261014-081150276-339510325`, failed too. Neither contributes a measured zero-time success.

The useful next investigation is sync lock scope and head-of-line blocking, followed by test execution and compiler work. A clean baseline needs a frozen client binary, stable compiler/Cargo identities, a quiet machine and repaired workload coverage. Compiler-phase attribution additionally needs a separate pass-timed diagnostic or native phase telemetry. No optimization was implemented in this profiling task.
