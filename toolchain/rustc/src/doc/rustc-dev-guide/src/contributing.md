# Working on the owned compiler

The justrust root `AGENTS.md` and `CONTRIBUTING.md` govern this source tree.
Compiler changes are made directly in `toolchain/rustc`, with build and validation
instructions in root `docs/toolchain-vendoring.md`. Upstream contribution approval,
reviewer assignment, branch, rebase, and AI-use policies do not govern this fork.

Technical material remains in [compiler architecture](overview.md),
[building](building/how-to-build-and-run.md), and [compiler tests](tests/intro.md).
