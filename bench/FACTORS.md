## Factors and workloads

- **depcache**: shared dependency cache: restore dependency rlibs instead of compiling. Workload `desktop-cold-check` (cold): fresh target dir (a new checkout, worktree, or slot); the cache was filled by one earlier build. Off: `{'JUSTRUST_DEPCACHE': '0', 'JUSTRUST_BUILD_SCRIPT_CACHE': '0'}`. Result: `factors-20261010-204006-c3c63f0156d5-dirty.json` (justrust c3c63f0156d5).
- **build-script-cache**: replay registry build-script runs (OUT_DIR + output) instead of running them. Workload `desktop-cold-check` (cold): fresh target dir with the depcache warm in both variants. Off: `{'JUSTRUST_BUILD_SCRIPT_CACHE': '0'}`. Result: `factors-20261010-194503-f7c1b3e840c7-dirty.json` (justrust f7c1b3e840c7).
- **localcache-revert**: local crate cache: restore workspace crates whose sources match an earlier build (JUSTRUST_LOCALCACHE=1), on undoing an edit. Workload `desktop-test-edit` (revert): edit fps_counter.rs, build (unmeasured, `edit_wall` = the miss path with staging), undo, build (measured); each variant keeps its own warm target dir. Off: `{'JUSTRUST_LOCALCACHE': '0'}`. Result: `factors-20261011-221705-a2c6ad1308d2-dirty.json` (justrust a2c6ad1308d2).
- **localcache-revert-sde**: same, with SOURCE_DATE_EPOCH fixed (Desktop's build.rs then stops stamping the build time into the UI crate through env!). Workload `desktop-test-edit` (revert): without it, JCODE_DESKTOP_BUILD_ID (build time in ms) differs every build and the UI crate never hits. Off: `{'JUSTRUST_LOCALCACHE': '0', 'SOURCE_DATE_EPOCH': '1791700000'}`. Result: `factors-20261011-230158-adeeaebe403f-dirty.json` (justrust adeeaebe403f).
- **localcache-revert-small**: same, on this repo's snapshot (one crate, full `test`). Workload `justrust-body-test` (revert). Off: `{'JUSTRUST_LOCALCACHE': '0'}`. Result: `factors-20261011-230158-adeeaebe403f-dirty.json` (justrust adeeaebe403f).
- **localcache-loop**: same cache, cost on the plain edit loop (every build misses and stages its outputs). Workload `desktop-test-edit` (loop): the background finisher hashes the 285 MB test binary niced while the next sample may start. Off: `{'JUSTRUST_LOCALCACHE': '0'}`. Result: `factors-20261012-001556-fc0cd2778c87-dirty.json` (justrust fc0cd2778c87).
- **localcache-fresh**: same cache, on a fresh target dir of unchanged sources (new slot, cargo clean). Workload `desktop-test-edit` (fresh): no edit; dependencies come from the private depcache in both variants, the warmup round fills both caches. Off: `{'JUSTRUST_LOCALCACHE': '0', 'SOURCE_DATE_EPOCH': '1791700000'}`. Result: `factors-20261011-233833-2b487ca729a9-dirty.json` (justrust 2b487ca729a9).
- **feature-unify**: resolve dependency features once per workspace, so -p switches reuse builds. Workload `desktop-pkg-switch` (sequence): fresh target dir, depcache off, three `check -p` in a row (the switch cost without caches hiding it). Off: `{'JUSTRUST_UNIFY_FEATURES': '0'}`. Result: `factors-20261010-194503-f7c1b3e840c7-dirty.json` (justrust f7c1b3e840c7).
- **slots**: per-agent target dirs: a second agent does not wait on the first one's build lock. Workload `desktop-two-agents` (concurrent): agent A runs `build -p jcode-desktop-ui` after a ui-core body edit; agent B starts 1s later with the reference loop (test-fn edit, `test --lib -- fps_counter`); B's wall is measured.
